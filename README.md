# HezhongSkywars ( HSW )
A Simple open-source Minecraft SkyWars plugin, supports mc 1.8 ~ latest.

## Technologies and Features
1. Single server support. HSW can run multi game arenas on a single server.
2. BungeeCord cross-server support. We coded an advanced network protocol that based on Redis. It can balance the players across different server instances.
3. Independent arena. HSW can modify tab list and block cross-arena chat messages。
4. and more
